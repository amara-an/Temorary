## 신규 동작 요구: 월간 근무표 인라인 입력

- 월간 근무표에서 직원 × 날짜 **셀을 클릭하면 그 셀 자체가 빈 키보드 입력칸이 된다.**
- 엑셀 빈 셀처럼 `A7`, `B5`, `휴`, `연` 등의 근무 코드를 **직접 키보드로 입력**한다.
- 셀을 편집하는 동안 기존 값은 확정 전까지 보존하며, 취소하면 기존 값으로 돌아간다.
- 이번 기본형에서는 별도 풀다운 메뉴나 큰 팝업 창을 필수로 만들지 않는다.
- 입력/저장과 직원 화면 **반영(게시)**은 구분한다.

## 월간 근무표 유지 조건

- **번호 / 이름**만 왼쪽에 고정. **그룹 열은 삭제.**
- 날짜 열(말일까지) 가로 스크롤, 직원 열 세로 스크롤 모두 시트 내부에서 작동.
- 각 날짜 아래에는 `오전+롱 / 오후+롱` 배정인원 두 숫자만 표시. 별도 설명 셀 없음.
- `휴`, `연`만 색상을 특별히 적용. 반일 휴무의 오전/오후 절반 색상 표시 유지.
- 날짜 선택 시 우측 패널에서 휴무 추가·삭제·변경 가능. 비고·메모 없음.
- 월 선택 옆에 휴무 신청 마감일 설정.
- 마지막 날짜 다음에 직원별 월 근무시간 합계 열.
- 하단 코드는 **오전 / 롱 / 오후** 구역의 코드와 출퇴근시간을 간단히 표시.

## 코드 관리 유지 조건

- `통상/연장`이 아닌 **롱**으로 구분.
- 출근시간과 퇴근시간은 직접 설정.
- **근무시간은 출퇴근시간의 차이로 자동 계산하지 않고 수동 입력**.
- 근무 코드 추가·수정·삭제, 코드 표시색 설정, `휴`·`연` 색상 변경 가능.

## 엑셀 내보내기 (추가 확정: 2026-11-14)

- 월간 근무표 **우상단의 `저장` 바로 옆에 `엑셀 내보내기` 버튼**을 추가한다. 우상단 배열은 `저장 | 엑셀 내보내기 | 반영(게시)`.
- 클릭 시 **현재 선택한 월의 근무표를 실제 Excel `.xlsx` 파일로 내보낸다**. 단순 화면 캡처나 PDF가 아니다.
- 사용자 제공 **11월 종이 근무 현황표 사진의 구조를 참조**한다: 상단 월 제목과 날짜·요일, 직원별 번호·이름과 날짜별 근무 코드, `휴`/ `연` 색상, 맨 오른쪽 직원별 월 근무시간, 하단의 코드별 출퇴근시간 참조표.
- 실제 웹폼에서 삭제하기로 한 **그룹 열은 Excel에도 다시 추가하지 않는다**. 불필요한 비고·메모·코드별 인원 집계 표도 추가하지 않는다.
- 하단 근무 코드 참조표는 현행 기본폼에 맞춰 **오전 / 롱 / 오후**로 나누고, 각 항목은 `코드 06:00 - 15:00` 형식으로 적는다.
- **근무시간은 출퇴근시간 차이로 자동 추산하지 않는다**. 코드 관리에서 수동 입력한 근무시간과 월 근무시간 값을 사용한다.
- 해당 월의 실제 날짜 수(28~31일), 표 테두리·셀 폭·인쇄 방향 등을 종이 근무표처럼 열람·인쇄하기 편하게 설정한다.
- `내보내기`는 `저장`이나 `반영(게시)`을 대신하지 않으며, 직원용 화면에 자동 게시하지 않는다.
- **현재 단계는 기능 명세 저장까지만** 한다. Excel 생성 기능을 실제 웹앱에 구현·테스트한 상태는 아니다.
