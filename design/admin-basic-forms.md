# 관리자 기본 폼 기준 (2026-11-14)

## 확정된 기본 시안 2장

현재 단계는 디자인 참조와 동작 명세 저장만 한다. **실제 웹앱 구현이나 배포는 아직 하지 않는다.**

1. **월간 근무표** — 이미지 원본 `admin_monthly_schedule_base.png`
2. **근무 코드 관리** — 이미지 원본 `admin_shift_code_management_base.png`

두 이미지 원본은 ChatGPT Library의 `/LeaveCalendar/design/`에 각각 저장해 두었다. 같은 위치에 상세 명세 `admin_basic_forms_spec.md`도 있다. 이 문서와 무관한 종전의 다른 시안은 기본 폼으로 사용하지 않는다.

## 신규 동작 요구: 월간 근무표 인라인 입력

- 월간 근무표에서 직원 × 날짜 **셀을 클릭하면 그 셀 자체가 빈 키보드 입력칸이 된다.**
- 엑셀 빈 셀처럼 `A7`, `B5`, `휴`, `연` 등의 근무 코드를 **직접 키보드로 입력**한다.
- 셀을 편집하는 동안 기존 값은 확정 전까지 보존하며, 취소하면 기존 값으로 돌아간다.
- 이번 기본형에서는 별도 풀다운 메뉴나 큰 팝업 창을 필수로 만들지 않는다.
- 입력/저장과 직원 화면 **반영(게시)**은 구분한다.

## 월간 근무표 유지 조건

- **번호 / 이름**만 왼쪽에 고정. **그룹 열은 삭제.**
- 날짜 열(말일까지) 가로 스크롤, 직원 열 세로 스크롤 모두 시트 내부에서 작동.
- 각 날짜 아래에는 `오전+롱 / 오후+롱` 배정인원 두 숫자만 표시. 별도 설명 셀 없음.
- `휴`, `연`만 색상을 특별히 적용. 반일 휴무의 오전/오후 절반 색상 표시 유지.
- 날짜 선택 시 우측 패널에서 휴무 추가·삭제·변경 가능. 비고·메모 없음.
- 월 선택 옆에 휴무 신청 마감일 설정.
- 마지막 날짜 다음에 직원별 월 근무시간 합계 열.
- 하단 코드는 **오전 / 롱 / 오후** 구역의 코드와 출퇴근시간을 간단히 표시.

## 코드 관리 유지 조건

- `통상/연장`이 아닌 **롱**으로 구분.
- 출근시간과 퇴근시간은 직접 설정.
- **근무시간은 출퇴근시간의 차이로 자동 계산하지 않고 수동 입력**.
- 근무 코드 추가·수정·삭제, 코드 표시색 설정, `휴`·`연` 색상 변경 가능.

## 이후 작업

**직원/그룹 관리 화면과 자동배정 기능은 나중에 추가**한다. 기본 시안 두 장 이외의 화면을 임의로 추가하거나 재배치하지 않는다.
