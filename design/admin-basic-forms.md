# 관리자 기본 폼 기준 (2026-11-14)

현재 단계는 디자인 참조와 동작 명세 저장만 한다. **실제 웹앱 구현이나 배포는 아직 하지 않는다.**

두 이미지 원본은 ChatGPT Library의 `/LeaveCalendar/design/`에 각각 저장해 두었다. 같은 위치에 상세 명세 `admin_basic_forms_spec.md`도 있다. 이 문서와 무관한 종전의 다른 시안은 기본 폼으로 사용하지 않는다.

## 신규 동작 요구: 월간 근무표 인라인 입력

- 월간 근무표에서 직원 × 날짜 **셀을 클릭하면 그 셀 자체가 빈 키보드 입력칸이 된다.**
- 엑셀 빈 셀처럼 `A7`, `B5`, `휴`, `연` 등의 근무 코드를 **직접 키보드로 입력**한다.
- 셀을 편집하는 동안 기존 값은 확정 전까지 보존하며, 취소하면 기존 값으로 돌아간다.
- 이번 기본형에서는 별도 풀다운 메뉴나 큰 팝업 창을 필수로 만들지 않는다.
- 입력/저장과 직원 화면 **반영(게시)**은 구분한다.

## 월간 근무표 유지 조건

- **번호 / 이름**만 왼쪽에 고정. **그룹 열은 삭제.**
- 날짜 열(말일까지) 가로 스크롤, 직원 열 세로 스크롤 모두 시트 내부에서 작동.
- 각 날짜 아래에는 `오전+롱 / 오후+롱` 배정인원 두 숫자만 표시. 별도 설명 셀 없음.
- `휴`, `연`만 색상을 특별히 적용. 반일 휴무의 오전/오후 절반 색상 표시 유지.
- 날짜 선택 시 우측 패널에서 휴무 추가·삭제·변경 가능. 비고·메모 없음.
- 월 선택 옆에 휴무 신청 마감일 설정.
- 마지막 날짜 다음에 직원별 월 근무시간 합계 열.
- 하단 코드는 **오전 / 롱 / 오후** 구역의 코드와 출퇴근시간을 간단히 표시.

## 코드 관리 유지 조건

- `통상/연장`이 아닌 **롱**으로 구분.
- 출근시간과 퇴근시간은 직접 설정.
- **근무시간은 출퇴근시간의 차이로 자동 계산하지 않고 수동 입력**.
- 근무 코드 추가·수정·삭제, 코드 표시색 설정, `휴`·`연` 색상 변경 가능.

## 엑셀 내보내기 (추가 확정: 2026-11-14)

- 월간 근무표 **우상단의 `저장` 바로 옆에 `엑셀 내보내기` 버튼**을 추가한다. 우상단 배열은 `저장 | 엑셀 내보내기 | 반영(게시)`.
- 클릭 시 **현재 선택한 월의 근무표를 실제 Excel `.xlsx` 파일로 내보낸다**. 단순 화면 캡처나 PDF가 아니다. 일일 양식 기능이 구현되면 월간 시트와 날짜별 일일 시트를 **동일한 통합문서 하나**에 함께 생성한다.
- 사용자 제공 **11월 종이 근무 현황표 사진의 구조를 참조**한다: 상단 월 제목과 날짜·요일, 직원별 번호·이름과 날짜별 근무 코드, `휴`/ `연` 색상, 맨 오른쪽 직원별 월 근무시간, 하단의 코드별 출퇴근시간 참조표.
- 실제 웹폼에서 삭제하기로 한 **그룹 열은 Excel에도 다시 추가하지 않는다**. 불필요한 비고·메모·코드별 인원 집계 표도 추가하지 않는다.
- 하단 근무 코드 참조표는 현행 기본폼에 맞춰 **오전 / 롱 / 오후**로 나누고, 각 항목은 `코드 06:00 - 15:00` 형식으로 적는다.
- **근무시간은 출퇴근시간 차이로 자동 추산하지 않는다**. 코드 관리에서 수동 입력한 근무시간과 월 근무시간 값을 사용한다.
- 해당 월의 실제 날짜 수(28~31일), 표 테두리·셀 폭·인쇄 방향 등을 종이 근무표처럼 열람·인쇄하기 편하게 설정한다.
- `내보내기`는 `저장`이나 `반영(게시)`을 대신하지 않으며, 직원용 화면에 자동 게시하지 않는다.
- **현재 단계는 기능 명세 저장까지만** 한다. Excel 생성 기능을 실제 웹앱에 구현·테스트한 상태는 아니다.

## 일일 근무표 양식 편집 및 통합 엑셀 출력 (구현 예정)

- 별도의 월간→일간 변환 앱을 만들지 않고, **관리자 웹앱에 일일 근무표 양식 만들기·수정 기능**을 넣는다.
- 한글에서 엑셀로 바뀌었을 뿐 기본 작업은 **표를 만들고 셀에 내용을 배치하는 일**이다. **완전한 엑셀 편집기 구현은 불필요**하다.
- 관리자는 일일 표의 **행·열 개수, 셀 크기, 병합, 글자·정렬·테두리 등의 기본 서식**을 편집하고 양식으로 저장·재사용할 수 있다.
- 양식 속 필요한 셀 또는 영역을 **날짜·직원 이름·근무 코드·출근시간·퇴근시간 등 월간 근무표 데이터와 연결**한다. 양식의 실제 셀 배치와 항목은 이후 제공되는 최신 일일 근무표 형식에 맞춘다.
- **월간 근무표가 단일 원천 데이터**이고, 내보낼 때 저장한 일일 양식에 선택 월의 날짜별 데이터를 채운다. 데이터를 일일 표에 다시 수작업으로 입력하지 않는다.
- 내보내기 결과는 **Excel 파일 하나**: 첫 시트 `월간 근무표`, 나머지는 해당 월의 날짜별 `1일`, `2일`, ... `28~31일` 시트. 날짜별 별도 파일이나 ZIP은 만들지 않는다.
- 기존 **우상단 `엑셀 내보내기` 버튼**을 이용한다. 양식 편집 기능은 나중에 추가하고, 지금은 요구사항만 기록한다.
- 자동 계산이 아니라 **코드 관리에서 직접 입력한 근무시간**을 기준값으로 사용한다. 계산이나 양식 임의 변경으로 실제 근무시간을 추정하지 않는다.

## 직원 관리 기본 규칙 (2026-11-14 확정)

- 화면 이름은 **직원 관리**로 한다. **그룹 관리 기능은 이번 범위에서 완전히 제외**한다.
- 관리 항목은 **직원 이름 목록**, **직원 추가**, **직원 삭제(활성 근무자 명단에서 제외)**만 둔다.
- 추가한 직원은 **관리자 월간 근무표의 직원 목록** 및 **직원의 휴무 신청 기능**에 연동한다.
- 삭제한 직원은 새 스케줄 작성·휴무 신청의 활성 목록에서는 제외하되, **이미 작성된 근무표와 휴무 이력은 보존**한다.
- **그룹 태그, 그룹 구분, 허용 코드, 금지 코드, 관리 가능 여부, 사번, 직급, 부서 등은 입력 필드·제목 셀·기본값·표시 데이터 모두 만들지 않는다.**
- 관리자 월간 근무표, Excel 내보내기, 직원 개인 화면 어디에도 그룹 정보가 나타나지 않는다.
- **일반 직원에게 내부 분류·권한 정보를 노출하지 않는다**. 필요하지 않은 정보를 임의로 생성하거나 다른 화면에 추가하지 않는다.
- 직원 관리 화면은 **추후 구현**하되 그 범위는 이름 등록/삭제 및 위 연동으로 한정한다. 이 단계에서 직원 관리 디자인·기능을 실제 앱에 구현하지 않는다.

## 이후 작업

현재는 **월간 근무표·근무 코드 관리의 두 디자인을 기본 폼으로 유지**한다. 직원 관리는 위 명세대로 나중에 붙이고, 자동배정도 보류한다. 별도 요청 없이 그룹 기능이나 열을 복구하지 않는다.
